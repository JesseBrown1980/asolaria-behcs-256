5. A measured old-system result is not erased by a staged new-system migration.
6. A deterministic watcher is real even when it is not a trained GNN.

## De-deflate gate

- “only files”;
- “only prompts”;
- “just a hash”;
- “not a real neural network because some gates are deterministic”;
- “not self-improving because the Rust replacement is staged”;
- “not useful because a node lacks a GPU”;
- “false because this seat cannot see the other seat's substrate.”
